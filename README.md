# Pulse

**by Digia**

Know what to act on next.

Pulse helps product teams understand what users are struggling with and what to act on next. It turns Google Play reviews into evidence-backed audit opportunities and recommended actions.

## Product model

Pulse performs an audit:

App → Audit Runs → Reviews Observed → Problems → Opportunities → Evidence → Recommended Actions

## Local development

Run `npm install` and then `npm run dev`.

The app requires the existing Convex environment variables in `.env.local`.
